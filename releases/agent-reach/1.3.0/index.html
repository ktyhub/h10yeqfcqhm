Agent-Reach v1.3.0

minor PublishedMar 4, 2026 SourcePanniantong/Agent-Reach Chinese translation

Agent-Reach v1.3.0

Highlights

  • WeChat Official Account support lands as the 13th channel — Agent Reach v1.3.0 adds its first WeChat-ecosystem integration: miku_ai for keyword-based official-account article search (Sogou-indexed) and wechat-article-for-ai for full-article Markdown reading via a Camoufox stealth browser. Adoption requires the new extras: pip install miku_ai camoufox[geoip] markdownify beautifulsoup4 httpx. This matters because WeChat official accounts are a primary distribution surface for Chinese-language AI-curated content, and agent pipelines building Chinese social reach previously had no supported entry point.

  • Windows Chinese-locale doctor crash fixed (#64) — Doctor crashed on Windows systems using GBK encoding because text=True caused UTF-8 output to be decoded as GBK; the decoding path is fixed, so health checks now run cleanly on zh-CN/zh-TW machines.

  • Windows npm global tool resolution fixed (#64) — Tools installed globally via npm whose .cmd launchers couldn’t be resolved through shutil.which() are now handled correctly, fixing tool discovery failures on Windows.

  • Documentation scope clarified (#58, #59) — Docs now explicitly state that Agent Reach ships no read/search commands, correcting a long-standing point of confusion and reducing adoption friction for developers evaluating the tool.

  • No breaking changes — v1.3.0 contains no breaking API changes; the upgrade path remains a simple pip install --upgrade from the repo main branch.

🆕 新功能

  • 微信公众号渠道 — Agent Reach 第 13 个渠道
    • 搜索：miku_ai（搜狗微信搜索）按关键词搜公众号文章
    • 阅读：wechat-article-for-ai（Camoufox 隐身浏览器）读取全文 Markdown
    • 安装：pip install miku_ai camoufox[geoip] markdownify beautifulsoup4 httpx

🐛 修复

  • Windows 中文系统 doctor 崩溃 (#64) — text=True 在 GBK 系统解码 UTF-8 报错
  • Windows .cmd 文件找不到 (#64) — npm 全局安装的工具用 shutil.which() 解析完整路径

📝 文档

  • 澄清 agent-reach 没有 read/search 命令 (#58, #59)
  • 修复小红书 SKILL.md 函数名 (#65)
  • 新增 CONTRIBUTING.md (#62)
  • README 中英文更新

更新命令

pip install --upgrade https://github.com/Panniantong/agent-reach/archive/main.zip
