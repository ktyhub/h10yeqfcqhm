patch PublishedNov 12, 2026 Sourceangular/angular Chinese translation

angular v22.2.6

Highlights

  • Runtime stability and memory — Fixes renderer and reference-retention leaks, removes stale event listeners after event replay, and ensures hydration failures release pending tasks. Resource URL properties now accept null and undefined; long-running and hydrated apps should upgrade.

  • HTTP behavior and bundle size — HttpParams now omits empty arrays, so applications with custom query-string handling should verify that behavior; synchronous interceptor errors also clean up pending tasks correctly. httpResource gains tree-shaking improvements for its initialization code and unused transfer cache.

  • Signal forms correctness — Touching a field flushes debounced descendant values, SignalFormControl preserves supplied options, and parseErrors updates no longer emit duplicate valueChanges events. Validators also stop tracking parseErrors, reducing unnecessary reactivity and control retention.

  • Templates, translations, and navigation — &ngsp; becomes a space inside ngNonBindable, compiler diagnostics and invalid ICU translation messages improve, and router fixes avoid unnecessary history.go() calls during canceled navigation and reloads when restoring URLs with the Navigation API.

  • Upgrade recommendation — This is a substantive patch release, not a re-tag or metadata-only update. No breaking changes or required migration steps are identified in the changelog; upgrade if you use the affected APIs or observe these symptoms, otherwise it is a routine maintenance upgrade that can be deferred.
