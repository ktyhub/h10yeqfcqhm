angular v22.2.0

minor PublishedSep 23, 2026 Sourceangular/angular Chinese translation

angular v22.2.0

Highlights

  • Template access and CSS encapsulation — Templates can now access private component properties, avoiding public getters used solely for binding; note that private is no longer a template-binding boundary. Nested CSS is now scoped correctly, while descendants of ::ng-deep avoid extra encapsulation—validate generated selectors if you rely on deep styling.

  • Earlier template errors, leaner @defer loading — The new strictUnclaimedEventNames compiler option catches misspelled output bindings that would otherwise leave event handlers inert. Keyed @defer blocks now receive scoped type checking, and deferred imports shared across blocks are deduplicated, reducing redundant loading.

  • Error boundaries beyond templates — Programmatic ErrorBoundary APIs and language-service support for @boundary blocks (#70463) let developers compose error handling in code rather than relying exclusively on template declarations, while improving editor tooling for declarative boundaries.

  • Signal forms and WebMCP metadata — Permanently hidden signal-form fields allow wizard steps or conditional sections to retain values without remaining visible. Implicit WebMCP signal forms now hard-code readOnlyHint and untrustedContentHint, and tool declarations accept annotations, giving clients explicit metadata instead of requiring behavioral assumptions.

  • Router resources and navigation semantics — Router resources and containsTree are now public, activated-route resources expose reload(), and throwing RedirectCommand can initiate redirects. Blocking now depends solely on resource-loading status, while rollbacks keep state frozen until loading completes; stabilized automatic injector cleanup also makes existing manual teardown worth reviewing.

  • Compatibility — No breaking changes are listed.
