MetaGPT v0.8.0

minor PublishedMar 29, 2024 SourceFoundationAgents/MetaGPT Chinese translation

MetaGPT v0.8.0

Highlights

  • Data Interpreter open-sourced — The flagship of this release: an autonomous agent that orchestrates notebooks, browser, shell, Stable Diffusion, and custom tools, self-debugs, and reports SOTA results on ML, mathematical reasoning, and open-ended tasks (paper: arXiv:2402.18679). It was restructured in #995 and got a critical fix in #1043 where the “human prior” was never injected — that silently changed task outcomes, so re-run any interpreter-based evaluations after upgrading.
  • Interpreter rename (migration watch-out) — Naming was unified and the class renamed via #901 and #952 (Interpreter → DataInterpreter). If you’re coming from 0.7.x, expect import paths and class names to have shifted, and notebook example locations moved (#1090); budget a quick pass over any code that imports the old symbol.
  • RAG module lands — as an opt-in — Indexing, retrieval, and ranking arrived in #974 and were extended in #1114, with a quick-start in roles/sales.py. The key adoption detail is #1070, which made RAG optional: adopters who don’t need retrieval won’t be forced to pull its dependencies, so you can layer it in incrementally rather than paying the full dependency cost up front.
  • Wider LLM support and a unified provider path — New backends: Claude via a dedicated Anthropic API (#961), QianFan and DashScope (#940), official Yi-34B (#1010), Mistral restored (#953), and user-supplied LLM config (#997). Notably, #946 folds OpenLLM, Fireworks, and other OpenAI-compatible services into the OpenAILLM class, so custom providers now funnel through one code path. Watch token accounting: #1020 adds gpt-3.5-turbo-0125 and #1042 fixes a bad URL in token_counter.
  • Behavioral fixes and new tooling — Reliability changes that affect runtime behavior: llm.timeout actually firing now (#1060), the “fail to reduce message length” runtime error (#986) and an indentation-induced JSONDecodeError (#963) fixed, and ipykernel bumped to 6.27.1 (#938). New tree (#985) and repo-to-markdown (#1061) commands make it easier to feed codebases into LLMs, while RFC197 (#960, example #968) and SECURITY.md (#970) formalize contribution and security policy.

No formally declared breaking changes in v0.8.0.

Release Highlights

Data Interpreter: Open Source and Better “Devin”

Data Interpreter is an autonomous agent that uses notebook, browser, shell, stable diffusion, and any custom tool to complete tasks.

Data Interpreter has achieved state-of-the-art scores in machine learning, mathematical reasoning, and open-ended tasks, and can analyze stocks, imitate websites, and train models.

It can debug code by itself, fix failures by itself, and solve a large number of real-life problems by itself.

We open-source our code and provide a wealth of working examples to give everyone access to state-of-the-art AI capabilities.

RAG

RAG module integrated! Common features such as indexing, retrieval, and rank are supported. Explore this example for a quick start.
