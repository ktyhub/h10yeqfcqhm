11/20
v1.6.0 minor ZH

GPT-6.2 Astra and GPT-6.2 Sol: both models are available on the openai, azure, and openai-codex providers, and GPT-6.2 Sol is now the default model for all three. See Providers.

 11/10
v1.5.2 patch ZH

Fork sessions whose folder is gone: when a session's original folder was moved or deleted, you can now fork it into the current folder instead of only continuing, so later resumes no longer ask.

 11/09
v1.5.1 patch ZH

Shell login and logout: use pi auth login and pi auth logout without starting a session, with API-key and no-browser sign-in options. See Credential commands.

 11/02
v1.5.0 minor ZH

Extension update changelogs: see what changed in installed extension packages on the next fresh launch after an update. Package authors can choose the changelog path, and collapseChangelog condenses the notices.

 10/21
v1.4.0 minor ZH

Image input for classifiers: codemode models.classify() accepts images for TypeSafe's Jev and Cloudflare's Clef models on typesafe, cloudflare-workers-ai, and OpenRouter. See Use classifier models and Codemode.

 10/15
v1.3.0 minor ZH

Choose where /share uploads: sessionShareDestination selects auto, gist, or radius. See Sessions and context and Export or share a session.

 10/12
v1.2.0 minor ZH

Per-key OpenRouter model lists: with an OpenRouter key, Pi lists only the models that key may use, with the key's context size, max output, and prices, including regional endpoints set in models.json. See OpenRouter.

 10/07
v1.1.0 minor ZH

Program status reporting: terminals and agent dashboards that support OSC 7501 see whether Pi is working, blocked on a dialog or login, done, or failed. See Program status.

 10/05
v1.0.4 patch ZH

Tool patterns and --no-mcp: --tools and --exclude-tools accept patterns, for example --tools read,codemode,'mcp__radius' keeps only one MCP server's tools.

 10/05
v1.0.3 patch ZH

Azure Foundry Chat Completions — The azure provider (renamed from azure-openai-responses) now also serves Foundry Chat Completions deployments, starting with azure/deepseek-v4-pro. See Azure OpenAI.

 10/04
v1.0.2 patch ZH

Sampling by thinking level — samplingParamsByThinkingLevel in models.json sets sampling parameters such as temperature and top_p for each thinking level on OpenAI-compatible APIs.

 10/03
v1.0.1 patch ZH

Nix flake — nix run github:earendil-works/pi/stable runs the latest release, and nix profile add github:earendil-works/pi/stable installs it. See Install pi.

 10/01
v1.0.0 major ZH

Fullscreen by default — The TUI now runs fullscreen. Set tuiMode to 'regular' to keep the terminal's normal scrollback. See Terminal and display.
