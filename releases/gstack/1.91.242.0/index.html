gstack v1.91.242.0

gstack v1.91.242.0 (weekly release)

First tagged release: the 96 versions since v1.91.146.0 (the week before it), one line each; the full changelog has every earlier one.

Team-mode installs follow the stable branch, which now points here; gstack-config set update_channel main follows every merge instead (docs/releases.md).

  • 1.91.242.0 (2026-10-26): gstack-context-bill now counts installed skills whose SKILL.md is a symlink, so it measures a real install. (#3423)
  • 1.91.241.0 (2026-10-26): Dependencies with known vulnerabilities (dompurify, the MCP SDK, zod, body-parser, fast-uri, ip-address) move to fixed releases. (#3463)
  • 1.91.240.0 (2026-10-26): Proactive skill suggestions default to the four core skills; core, all or off picks the set. (#3432)
  • 1.91.239.0 (2026-10-26): BROWSER.md now says that gstack’s own browser still trusts the compromised eMudhra intermediate certificates, and how to check (#3338). (#3403)
  • 1.91.238.0 (2026-10-26): gstack-gate-diff <base> works in a clone with no local <base> branch, and gstack-post no longer flags the repository’s own release versions as public IP addresses. (#3439)
  • 1.91.236.0 (2026-10-26): The merge queue now refuses a PR that never ran /ship. (#3438)
  • 1.91.234.0 (2026-10-26): gstack now publishes weekly tagged releases, and team-mode auto-update follows a new stable channel by default. (#3429)
  • 1.91.233.0 (2026-10-26): /plan-tune’s inferred profile no longer pins at 1.0 after a few reviews, and it now records how many answers moved each dimension. (#3397)
  • 1.91.231.0 (2026-10-26): A fresh install is about 520 MB smaller: ./setup installs production dependencies only. (#3426)
  • 1.91.230.0 (2026-10-26):
    • The page layout you pick on the /design-shotgun board now reaches /design-html, which builds with it instead of choosing again or asking. (#3422)
    • /design-html remembers the craft findings you accepted, so later runs report them as accepted instead of flagging them again; gstack-design-craft --accepted <finalized.json> reads that record. (#3422)
  • 1.91.228.0 (2026-10-26): Skills start at once on Windows again: the workflow lock no longer depends on symlinks (#3330). (#3424)
  • 1.91.227.0 (2026-10-26): On Windows, gstack’s record tools stop losing review, question, learning and timeline records when Git Bash path conversion is off (#3415). (#3431)
  • 1.91.226.0 (2026-10-26): /review can re-review just its own fixes after a fixing pass, under the same rules as /ship (#3339). (#3414)
  • 1.91.225.0 (2026-10-26): /design-html builds landing pages around one visitor action, with pages that look finished and no invented proof; adapted from Elaya’s design skills. (#3420)
  • 1.91.224.0 (2026-10-25): /context-restore now says when commits landed after a checkpoint was saved, instead of offering finished steps as the plan. (#3396)
  • 1.91.223.0 (2026-10-25): /plan-tune’s inferred profile finally moves: a clicked answer is logged as the question’s registered option, not its label. (#3394)
  • 1.91.221.0 (2026-10-25): The session-start updater no longer skips its own update because of its own session’s workflow lock. (#3412)
  • 1.91.220.0 (2026-10-25): A design doc edited in plan mode no longer goes stale for the plan reviews (#542). (#3408)
  • 1.91.218.0 (2026-10-25): gstack-team-init required now blocks skills when its check can’t run, instead of letting them through. (#3393)
  • 1.91.216.0 (2026-10-25): /sync-gbrain refuses to run while a gbrain autopilot is active, before it touches the brain’s source list (#3360; contributed by @exGeni). (#3386)
  • 1.91.215.0 (2026-10-25): An unattended /ship writes its final summary to a file under .gstack/tmp/, and the agent that started it is told to read that file. (#3409)
  • 1.91.214.0 (2026-10-25): gstack-brain-sync --publish-removals --yes no longer prints list: unbound variable when it finishes, and it now removes its temp list and releases the sync lock. (#3405)
  • 1.91.212.0 (2026-10-25): /careful no longer asks about words inside a commit message (#1060; contributed by @Bhumika-1432006). (#3389)
  • 1.91.211.0 (2026-10-25): gstack-diff-scope recognizes Python tests and nested test folders (#3335). (#3382)
  • 1.91.210.0 (2026-10-25): /autoplan works when Claude Code’s project folder is a subfolder of the repository (#3296). (#3383)
  • 1.91.208.0 (2026-10-25): The Capy install guide says the team-mode session-start updater also waits for running gstack workflows. (#3399)
  • 1.91.207.0 (2026-10-25): Per-repository session counts include sessions from removed Claude Code worktrees (contributed by @Shweta-Mishra-ai). (#3387)
  • 1.91.206.0 (2026-10-25): A repository that keeps .gstack/ out of git can still give /ship’s test selection a policy file, and name which CI jobs a local run counts for (#3286). (#3398)
  • 1.91.205.0 (2026-10-25): /ship can re-review just the fixes after a fixing pass, and a narrowed pass can never be the review that ships (#3339). (#3404)
  • 1.91.204.0 (2026-10-25): An unattended run is told to end with a GSTACK_RESULT line only when its skill can write one. (#3392)
  • 1.91.203.0 (2026-10-25): Asking gstack to fix a failure with a known cause now goes straight to the fix instead of always opening /investigate, and an unknown cause gets a short, bounded triage (#3157, #3158). (#3395)
  • 1.91.202.0 (2026-10-25): Team-mode auto-update waits for running gstack sessions instead of moving the checkout under them (#3363). (#3385)
  • 1.91.201.0 (2026-10-25): /ship’s specialist reviewers and /plan-eng-review use one severity scale, CRITICAL or INFORMATIONAL, the same one /review already uses (#3349). (#3402)
  • 1.91.200.0 (2026-10-25): /cso doctor no longer calls a Go repository “stack: python”. (#3378)
  • 1.91.199.0 (2026-10-25): When /sync-gbrain refuses because a gbrain autopilot is running, it says which process it found and what to do. (#3377)
  • 1.91.198.0 (2026-10-25): A second-opinion reviewer that says “not ready” is no longer reported as clean. (#3376)
  • 1.91.197.0 (2026-10-25): /ship’s test selection gives changed Rust files a test job, and runs a nested pnpm or vitest package with its own runner (#3344). (#3380)
  • 1.91.196.0 (2026-10-25): /land-and-deploy no longer stops parallel PRs with a false “VERSION drift detected”. (#3379)
  • 1.91.195.0 (2026-10-25): Four skill prompts stop contradicting their code: /health computes its GBrain score in code, /office-hours uses the right diff base, and /ios-qa’s demo rule and /plan-design-review’s model name are corrected. (#3373)
  • 1.91.194.0 (2026-10-25): A read-only repository can now opt in to Memorable recall, one remote at a time, and a corrupt policy store no longer turns the recall veto off. (#3381)
  • 1.91.193.0 (2026-10-25): On Windows, the browser’s terminal agent stops restarting every 60 seconds and stops flashing a console when Bun came from npm (#2295; contributed by @adammartin0087). (#3388)
  • 1.91.192.0 (2026-10-25): Batched merges (several ready PRs tested and merged together) stop refusing correct PRs and stop letting a damaged CHANGELOG through. (#3374)
  • 1.91.191.0 (2026-10-25): gstack-version-bump write --changelog moves the branch’s [Unreleased] entry under the new version, and /ship no longer treats a tentative place in the merge queue as confirmed. (#3372)
  • 1.91.189.0 (2026-10-25): gstack’s installer now defaults to Bun 1.4.4, and a stalled package mirror can no longer hold up a CI test shard for 20 minutes. (#3368)
  • 1.91.188.0 (2026-10-24): /ship’s test selection maps extensionless .jsx, .mts and .cts imports and index files to their tests (#3340). (#3371)
  • 1.91.187.0 (2026-10-24): Four docs now say what the code does: the unattended run contract, the approval reply format, the session-kind override and voice triggers. (#3367)
  • 1.91.186.0 (2026-10-24): Approving an /autoplan run no longer fails one time in ten because its run id looks like a card number. (#3366)
  • 1.91.182.0 (2026-10-23): gstack installs on a project that pins Bun 1.4.4 again. (#3345)
  • 1.91.181.0 (2026-10-23): /cso can run its sandboxed runtime checks: its catalog of vetted runtimes is now filled in. (#3343)
  • 1.91.180.0 (2026-10-22): The /cso docs name the vetted runtime and scanner catalogs instead of saying “static assessment only”. (#3337)
  • 1.91.178.0 (2026-10-22): A /qa run no longer gets a hint that another report folder could change its verdict. (#3341)
  • 1.91.172.0 (2026-10-20): gstack fits the way Capy runs agent work: every decision goes to a person in plain words, plan approvals use a fixed before-and-after layout, each thread records who approved what, and /ship’s PR body shows before-and-after images. (#3328)
  • 1.91.171.0 (2026-10-20): A restarted /ios-qa daemon resumes the device session instead of relaunching the app. (#3132)
  • 1.91.170.0 (2026-10-20): /autoplan no longer stops a healthy run with a false “event order” or “init” denial when Claude Code is slow to write its session journal. (#3326)
  • 1.91.161.0 (2026-10-19): /ship’s test selection works on Django, Dart and Flutter repositories, and on branches that change only assets or tool config. (#3306)
  • 1.91.160.0 (2026-10-19): Dart and Flutter projects get the right reviewers and the right test command. (#3300)
  • 1.91.159.0 (2026-10-19): Security: the repository gstack runs in can no longer configure gstack’s own programs through its .env or bunfig.toml. (#3312)
  • 1.91.158.0 (2026-10-19): gstack-config set plan_mode_preamble off leaves the plan-mode preamble out of every installed skill, for people who never use plan mode. (#3308)
  • 1.91.157.0 (2026-10-19): Claude SKILL.md files no longer include a “When to invoke” body section, which saves about 20 KB across 56 skills. (#3305)
  • 1.91.155.0 (2026-10-19): A busy page no longer locks up the browser daemon. (#3301)
  • 1.91.154.0 (2026-10-19): /cso can verify Rails repairs in a read-only checkout, no longer brings back credential files through retained Git history, and reports a repair whose checks fail as ASSERTION_FAILED instead of a misleading INCOMPATIBLE_INPUT. (#3302)
  • 1.91.153.0 (2026-10-19): A second-model review whose findings are untagged prose no longer reads clean because a “no issues” phrase appears somewhere in it, and a clean Codex review that says “no actionable regressions” no longer reads unverified. (#3304)
  • 1.91.152.0 (2026-10-19): /cso now starts and finishes on repositories that hold a nested Git repository, a long patch history, or a Docker socket on macOS 27. (#3303)
  • 1.91.151.0 (2026-10-19): A saved “never ask” now sticks for /plan-eng-review’s structure question, /context-save and /context-restore close three checkpoint gaps, and a new how-to covers the first production deploy. (#3299)
