DocsGPT 0.10.0

minor PublishedJul 18, 2024 Sourcearc53/DocsGPT Chinese translation

DocsGPT 0.10.0

Highlights

  • Internationalization goes live — Full i18n is wired in via i18next (#969), with Japanese (#987) and Mandarin (#991) translations plus auto-detection of the user’s browser locale (#1032), and translated conversation-history dropdown (#972). This is the headline feature of 0.10.0: if you serve non-English users, upgrading turns on a localized UI with no per-user config; English-only deployments gain nothing here beyond the underlying refactor.

  • New deployment and sharing capabilities — Adds Kubernetes deployment manifests (#963), sharing endpoints (#1034), and token accounting for vectors (#964) with denominations shown to users (#990). Self-hosters standardizing on k8s get a supported path, and teams tracking embedding/LLM costs gain visibility; operators on plain Docker or with no cost-tracking needs can treat these as optional.

  • Conversation UX and reliability fixes — Adds a clear-chat-history button (#929), a dropdown to adjust conversation-history limits (#965), a copy button for code snippets (#955), and clickable links from remote sources back to their original URL (#970). Also fixes empty conversation responses (#967), improves /stream error handling (#1002), remote upload errors (#933), API key parsing (#952), and mobile overflow/word-break issues (#942). Worth upgrading for anyone whose users hit these front-end and streaming issues day to day.

  • Security and dependency maintenance — Several bumps with real security impact: braces 3.0.2→3.0.3 (#1006, #1011, #1029, #1033) addresses a known ReDoS advisory, alongside werkzeug 3.0.1→3.0.3 (#939), requests 2.31.0→2.32.0 (#961), next 14.0.4→14.1.1 (#943), and qdrant-client 1.8.2→1.9.0 (#979). These alone justify the upgrade for internet-facing installs, even if none of the features above appeal.

  • Migration watch-outs and who can skip — No formal breaking-change note, but three items need checking: celery.py was renamed (#994), which will break any custom scripts, service definitions, or CI referencing that path; embeddings instantiation was refactored to a singleton pattern (#996) with a matching singleton fix in llama_cpp (#1013), relevant if you integrate at the code level; and the base image moved to Ubuntu 24.04 (#1000) with updated multi-platform build targets (#958), so verify your build/pull pipeline. If you’re on a stable 0.9.x setup with no need for i18n, k8s, or the security patches, this can wait.
