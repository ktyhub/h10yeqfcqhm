DocsGPT 0.13.0

minor PublishedFeb 3, 2025 Sourcearc53/DocsGPT Chinese translation

DocsGPT 0.13.0

Highlights

  • Tools and agent framework (the headline change) — 0.13 introduces a first-class tool/agent layer: the tools UI and endpoints were refactored in #1502 and #1581 (action parser + handlers), with a Postgres tool (#1600) and a generic API Tool (#1608) shipping alongside the agent loop in #1473. This effectively turns DocsGPT from a RAG Q&A box into an agentic platform where the model can call external systems. If you’ve built against the older tool endpoints or customized the tools UI, budget time to re-wire those integrations.

  • Google AI / Gemini as a model backend — #1441 adds Google AI as a provider and #1594 brings the tools framework into compatibility with it. That gives you a second first-class model family next to OpenAI, but tool calling is provider-specific — validate your tool definitions against Google AI before switching production traffic.

  • React Widget 0.4.8 → 0.4.9 — The embeddable widget picks up a search bar component (#1436, #1527), hover states (#1531) and a round of fixes (#1450, #1570, #1549). The one to watch is the ingestor type refactor for remote resources (#1610): if you feed remote URLs through the widget, re-check your upload prop shapes when moving from 0.4.x to 0.4.9.

  • Conversation behavior changes — Streaming responses are smoother (#1437) and several correctness bugs are fixed: stale streamed answers leaking into new conversations (#1443), edit-and-resend (#1444), and deleting downstream queries when a message is edited (#1461). Separately, #1500 caps conversational history — long threads will now be truncated, so anything relying on unbounded context should revisit its prompt strategy.

  • Ingestion and search got a real upgrade — Large ZIPs no longer break the streaming endpoint (#1303), multi-file uploads were fixed (#1422), and training files can be dragged straight into the input box (#1463). Search gained a backend implementation and table styling (#1442) plus similar-substring highlighting (#1475), while a markdownify-based scraper (#1582) and web-loader fix (#1588) improve remote source quality.

  • Dependency majors to regression-test — The frontend jumps react-router-dom 6 → 7 (#1508) and i18next 23 → 24 (#1507); the backend moves numpy 1.26 → 2.2 (#1509), torch 2.4 → 2.5 (#1546), Flask 3.0 → 3.1 (#1577) and langchain-openai 0.2 → 0.3 (#1567). The router and numpy leaps are the most likely to break custom frontend code or binary extensions — plan a targeted upgrade pass rather than a blind bump.
