OpenCLI v1.7.19

patch PublishedMay 13, 2026 Sourcejackwener/OpenCLI Chinese translation

OpenCLI v1.7.19

Highlights

  • Browser session API is now positional — --session has been replaced by a <sessionname> positional argument (#1505), and session plumbing was tightened: the “lease key” backdoor was removed (#1510), OPENCLI_KEEP_TAB was dropped (#1509), and session injection no longer appears in extension exec results (#1518). Scripts and adapters that pass --session foo or relied on implicit session inheritance will break — migrate callers to the positional form and make session selection explicit.
  • Node 20+ becomes the baseline — removal of util.styleText (#1524) raises the minimum Node version to v20. Check your runtime before upgrading; older Node installs will fail at load time, so this is a silent-upgrade hazard rather than a feature.
  • page.evaluate now accepts a function form — (#1508) you can pass an actual function instead of only string expressions, which makes evaluated browser logic type-checkable and avoids string-escaping pitfalls. Existing string-based calls still work, so adoption is opt-in.
  • Expanded read coverage for Reddit, Zhihu, and Ctrip — new commands include Reddit whoami/home/subreddit-info (#1491), --expand-more via /api/morechildren with 7 typed error kinds (#1492), Zhihu answer pagination (#1517) and answer-detail for full single-answer content (#1528), and Ctrip hotel-search plus flight browser-mode commands (#1489). The typed errors in particular let callers distinguish failure modes instead of parsing messages.
  • Twitter adapters repaired against the 2026-05 site changes — search/readback (#1512), reply submission (#1511), list/following endpoints (#1503), and a raised cursor pagination guard (#1532) were all fixed. Note a behavioral change in #1531: bare tweets now defaults to the logged-in user, and a sibling envelope-unwrap bug that silently dropped data was corrected — audit any code that assumed the old empty-argument behavior.
  • Correctness fixes where upstream DOM/locale drift silently broke scrapers — finance dates now render in Asia/Shanghai rather than UTC (#1498), evaluate returns are wrapped so Array.isArray and serialization work in Google Search/Scholar (#1523, #1525), Xiaohongshu parses 2.1w/1.5万/1.2k like-counts (#1504) and falls back to href-based note cards when section.note-item is dropped (#1507, with --limit > 13 scroll fix in #1487). Adapter authors should also treat aria-label/placeholder/title as locale-dependent (#1488) — selectors keyed on English text are fragile.
